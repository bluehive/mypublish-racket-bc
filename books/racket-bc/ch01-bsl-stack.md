数をしまうときに、「どこへ追加し、どこから取り出すか」を決めると、操作を整理できます。この章では、皿の山を手掛かりにその約束を考え、数の並びとして表します。そのあとで`first`・`rest`・`cons`を試し、操作に名前を付け、テストで確かめます。

## 1.1 スタックとは？ 皿の山を思い浮かべよう

皿を上に一枚ずつ重ねた山を考えます。上から新しい皿を置き、取り出すときも一番上から取ります。途中の皿だけを抜き取らない、という約束です。

数を置く場所でも、追加するのと取り出すのを同じ端で行うと、最後に置いた数から使うことになります。この仕組みを**スタック**と呼びます。英語のstackには「積み重ね」という意味があります。

```text
2を積む       その上に3を積む       一番上を除く
              ┌───┐
              │ 3 │ ← 一番上
┌───┐         ├───┤                 ┌───┐
│ 2 │         │ 2 │                 │ 2 │
└───┘         └───┘                 └───┘
```

最後に積んだ3を先に使います。この約束を「後入れ先出し」と呼ぶこともあります。一番上を**トップ（top）**、積む操作を**プッシュ（push）**、一番上を除く操作を**ポップ（pop）**と呼びます。図では、あとから置いた3が一番上にあり、先に置いた2はその下に残っています。

電卓では、ここへ計算の材料となる数を積みます。たとえば2の上に3を積んだら、足し算でこの二つを使えます。まずは、積む操作と一番上を読む操作を作りましょう。

## 1.2 数の並びをリストで表す

スタックをプログラムで表すために、**リスト**を使います。リストは、値を決まった順序で並べたものです。3、2という二つの数を並べる場合と、2、3という順に並べる場合では、先頭の数が違います。スタックでは、この順序が重要です。

「はじめに」で作った`practice.rkt`をRunしたあと、次の式を**対話エリアへ一行ずつ**入力してください。

```racket
(list 3 2)
(list 8)
'()
```

`(list 3 2)`は3、2の順のリスト、`(list 8)`は8だけのリストです。`'()`は、何も入っていない**空リスト**です。先頭の`'`も含めて入力します。0とは違います。0の入ったリストは`(list 0)`です。

本書では、**リストの左端をスタックの一番上**にします。`(list 3 2)`ならトップは3です。数を積んだ順番は2→3ですが、リストでは3、2の順になります。

DrRacketの設定によって、答えのリストは`(cons 3 (cons 2 '()))`のように表示されることもあります。次に学ぶ`cons`を重ねた表し方で、`(list 3 2)`と同じ内容です。表示の見た目が違っても、値の並びを比べましょう。

## 1.3 firstは先頭、restは残り、consは先頭に追加

リストを扱うために、BSLが用意している三つの**関数**を使います。関数は、材料を受け取って答えを返す仕組みです。「はじめに」の`+`も、二つの数を受け取って和を返す関数でした。渡す材料を**引数**、返ってくる答えを**戻り値**と呼びます。

| 関数 | すること | 式 | 答え |
|---|---|---|---|
| `first`（ファースト） | リストの先頭の値を得る | `(first (list 3 2))` | `3` |
| `rest`（レスト） | 先頭を除いた残りのリストを得る | `(rest (list 3 2))` | `(list 2)` |
| `cons`（コンス） | 値をリストの先頭に付けた、新しいリストを得る | `(cons 4 (list 3 2))` | `(list 4 3 2)` |

表の式を対話エリアで一つずつ試してください。この例の`first`は先頭にある数を返し、`rest`は残りのリストを返します。`(rest (list 8))`の答えは`'()`になります。**一個のリストから先頭を除くと、空になる**ためです。

`cons`の材料は二つです。一つ目に付けたい値、二つ目に付け先のリストを渡します。空リストにも追加できます。

```racket
(cons 2 '())
;; 答えは (list 2)
(cons 3 (cons 2 '()))
;; 答えは (list 3 2)
```

内側の`(cons 2 '())`を先に考えると読みやすくなります。まず2だけのリストを作り、その先頭に3を付けています。`(cons 3 2)`は、二つ目がリストではないので、この言語ではエラーです。

`first`と`rest`は、空リストには使えません。先頭が存在しないためです。**`(first '())`と`(rest '())`はどちらもエラー**です。この章の後半で、使う前に空かどうかを調べます。

## 1.4 check-expectで答え合わせする

同じ式を何度も確かめるときには、予想した答えをプログラムと一緒に保存しておくと便利です。実行結果が予想と一致するかを確認する仕組みを、**テスト**と呼びます。まず一つ、答え合わせを書いてみましょう。

```racket
(check-expect (first (list 3 2)) 3)
```

`check-expect`（チェック・エクスペクト）は、**一つ目の式を計算し、二つ目の期待する答えと同じかを確認**します。上の例では、実際の計算が`(first (list 3 2))`、予想が`3`です。3を返す関数ではなく、答え合わせのための書き方です。

次のテストを`practice.rkt`の**定義エリアの、最後の`(test)`の前**へ追加してRunします。

```racket
(check-expect (first (list 3 2)) 3)
(check-expect (rest (list 3 2)) (list 2))
(check-expect (cons 4 (list 3 2)) (list 4 3 2))
```

「はじめに」の足し算テストも残っていれば、合計4件が成功します。英語なら`All 4 tests passed!`のように出ます。表示の場所や言葉は環境によって違います。

一度、最初のテストの**予想だけを3から9に変えて**Runしてみましょう。テストが失敗し、実際は3だったことと予想の9との違いが示されます。今回は予想をわざと間違えたので、3へ戻します。実際のプログラムの間違いを直すときは、テストを通すためだけに予想を変えず、式と予想のどちらが正しいか考えます。

## 1.5 自分の関数に名前を付ける

これから、スタックの操作を`push`・`top`・`pop`という名前で呼べるようにします。まず、数を積む関数を**定義エリアのテストより前**へ一度だけ追加します。

```racket
(define (push n s) (cons n s))
```

`define`（ディファイン）は、自分で名前と働きを決める書き方です。`push`が関数名、`n`と`s`が受け取る材料の仮の名前、最後の`(cons n s)`が答えの作り方です。ここでは`n`を数、`s`をスタックとして使います。名前の文字に特別な力はありません。

`(push 3 (list 2))`と呼ぶと、`n`のところに3、`s`のところに`(list 2)`が入り、`(cons 3 (list 2))`を計算して`(list 3 2)`を返します。`n`と`s`は、呼ぶたびに渡される材料を受け取る場所です。別の数や別のリストを渡しても、同じ`(cons n s)`という作り方を使えます。

次のテストも最後の`(test)`の前に追加します。

```racket
(check-expect (push 3 (list 2)) (list 3 2))
(check-expect (push 3 (push 2 '())) (list 3 2))
```

元のリストを消したり書き換えたりする操作ではありません。たとえば、次の式で古いスタックに名前を付けてみます。これは関数ではなく、値への名前付けです。定義エリアに追加してRunします。

```racket
(define old-stack (list 2))
```

対話エリアで`(push 3 old-stack)`を試すと`(list 3 2)`、続いて`old-stack`を試すと元の`(list 2)`が得られます。**新しいスタックを使うには、その戻り値を次の計算へ渡す**必要があります。`old-stack`という名前で参照する値は、操作の前後で変わりません。二つの答えを並べて確かめると、元の値と新しく得た値を区別できます。

## 1.6 空かどうかを調べてtopとpopを作る

空かどうかを調べる`empty?`（エンプティ）は、`(empty? '())`なら`#true`、`(empty? (list 2))`なら`#false`を返します。この二つは「はい／いいえ」を表す値で、**真偽値**と呼びます。名前の末尾の`?`も関数名の一部です。

条件によって答えの作り方を二つに分けるのが`if`です。たとえば、空ならエラーを知らせ、空でなければ先頭を読む、と分けられます。

```text
(if 条件 はいのときの式 いいえのときの式)
```

これは形の説明なので、そのまま貼り付けるコードではありません。条件の答えによって、どちらか片方の式を計算します。次の定義を、テストより前へ追加しましょう。

```racket
(define (top s)
  (if (empty? s) (error "stack empty") (first s)))

(define (pop s)
  (if (empty? s) (error "stack empty") (rest s)))
```

`top`は、空でなければ`first`で先頭の数を返します。`pop`は`rest`で残りのリストを返します。`pop`が返すのは「外した数」ではありません。数を知りたいときは`top`を使います。

`error`は、問題を知らせて計算を止めます。`"stack empty"`は「スタックが空」というメッセージです。`" "`で囲んだ文字の並びを**文字列**と呼びます。引用符も半角で入力しましょう。

```racket
(check-expect (top (list 3 2)) 3)
(check-expect (pop (list 3 2)) (list 2))
(check-expect (pop (list 8)) '())
(check-error (top '()) "stack empty")
(check-error (pop '()) "stack empty")
```

このテストも`(test)`の前に追加します。`check-error`は、「この式は指定したメッセージのエラーになるはず」と確かめる仲間です。**エラーになることが正解のテスト**なので、成功してもプログラムの不具合ではありません。

## 1.7 複製・交換・全消去

スタックの基本ができたら、便利な操作を三つ作れます。次のコードを読む前に、表の結果を手で予想してみましょう。

| 名前 | 意味 | 入力（左がトップ） | 結果 |
|---|---|---|---|
| `dup`（デュープ） | 一番上をもう一個積む | `(list 4 1)` | `(list 4 4 1)` |
| `swap`（スワップ） | 上の二つを交換 | `(list 1 2 3)` | `(list 2 1 3)` |
| `clear`（クリア） | 全部なくす | `(list 1 2)` | `'()` |

```racket
(define (dup s) (push (top s) s))
(define (swap s)
  (push (top (pop s)) (push (top s) (pop (pop s)))))
(define (clear s) '())
```

`dup`はトップを読み、その数をもう一度積みます。`clear`は受け取った値にかかわらず空リストを返します。元のスタックを書き換えてはいません。

`swap`は少し長いので、`s`が`(list 1 2 3)`の場合を分けて読みます。

1. `(top s)`は1、`(top (pop s))`は2です。
2. `(pop (pop s))`は、上の二つを除いた`(list 3)`です。
3. 残りに1を積んで`(list 1 3)`、さらに2を積んで`(list 2 1 3)`にします。

追加テストは次の三つです。空のスタックの`dup`、数が一つしかないスタックの`swap`は、使う数が足りないためエラーになります。

```racket
(check-expect (dup (list 4 1)) (list 4 4 1))
(check-expect (swap (list 1 2 3)) (list 2 1 3))
(check-expect (clear (list 1 2)) '())
```

## 1.8 確かめ問題

式を対話エリアで試す前に、答えを予想してください。

1. `(first (list 9 4 1))`と`(rest (list 9 4 1))`の答えは、それぞれ数ですか、リストですか。
2. 空のスタックへ2、次に7を積む式と、その答えを書いてください。
3. `(pop (list 0))`と`(top '())`は、どちらも0になりますか。

**答え**：1は`9`（数）と`(list 4 1)`（リスト）。2は`(push 7 (push 2 '()))`で、答えは`(list 7 2)`。3は、前者が`'()`、後者がエラーです。

この章では、先頭を読む`first`、残りを得る`rest`、先頭へ付ける`cons`からスタックを作りました。次章では、その上の二つを取り出して計算します。数がどの順に並んでいるかを、引き続き確かめていきましょう。
